# real_time# Real-Time Neural Speech-to-Speech Translator (MVP)

यह एक ऐसा रियल-टाइम टू-वे ट्रांसलेशन प्रोजेक्ट है, जो फोन के माइक से लाइव आवाज लेकर उसे दूसरी भाषा में बदलकर सीधे ब्लूटूथ इयरफोन पर डिलीवर करता है।

## 📁 Project Structure
- `backend/` : FastAPI और WebSocket पर आधारित पायथन सर्वर।
- `frontend_app/` : Flutter (Android/iOS) मोबाइल ऐप का फ्रंट-एंड।
